# 边记 v0.1.0 发布说明

`v0.1.0` 是边记的第一个稳定可用版本。

## 核心功能

- 桌面透明标记层。
- macOS 顶部菜单栏控制。
- 画笔、直线、箭头、矩形、圆形。
- 预设颜色和系统色盘。
- 4 档线条粗细。
- 小笔光标。
- 撤回、清空、右键清空。
- `Esc` 暂停标记并恢复普通桌面操作。

## 快捷键

- `1` 画笔。
- `2` 直线。
- `3` 箭头。
- `4` 矩形。
- `5` 圆形。
- `[` 线条变细。
- `]` 线条变粗。
- `Cmd + Z` 撤回。
- `Cmd + K` 清空。
- `Esc` 暂停标记。
- 鼠标右键清空当前标记。

## 安装说明

下载 `Bianji-v0.1.0.zip` 后解压，将 `边记.app` 拖入 `Applications` 文件夹。

当前版本使用本地 ad-hoc 签名，没有 Apple Developer ID 正式签名。如果 macOS 提示无法验证开发者，可以右键点击 `边记.app`，选择 `打开`。

## 已知限制

- 暂不支持文字标注。
- 暂不支持截图导出。
- 暂不支持自动淡出。
- 暂不支持全局快捷键显示/隐藏。
- 暂未做 Apple notarization。

## 技术备注

当前版本不使用低层全局鼠标事件钩子。绘制交互基于 AppKit overlay window 和普通鼠标事件实现，优先保证系统稳定性。
