# 边记 v0.1.1 发布说明

`v0.1.1` 是边记的多显示器兼容性更新。

## 修复与改进

- 支持在多块显示器上分别绘制。
- 每块屏幕只显示属于自己的笔迹，避免跨屏镜像。
- 修复副屏坐标原点被重复计算，导致超宽屏只有右侧区域可以绘制的问题。
- 支持显示器插拔、分辨率变化和屏幕排列变化后的自动适配。
- 撤回只删除全局最后一笔，清空会清除所有显示器上的标记。
- 非活动显示器的首次点击也可以直接开始绘制。

## 安装说明

下载 `Bianji-v0.1.1.zip` 后解压，将 `边记.app` 拖入 `Applications` 文件夹。

当前版本使用本地 ad-hoc 签名，没有 Apple Developer ID 正式签名。如果 macOS 提示无法验证开发者，可以右键点击 `边记.app`，选择 `打开`。

## 安全性

本次更新继续使用 AppKit 原生窗口和鼠标事件，没有引入低层全局鼠标事件钩子。
