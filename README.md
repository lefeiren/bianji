# 边记

边记是一个轻量 macOS 桌面标记工具。

当前版本聚焦最核心的桌面标记流程：

- 直接在电脑桌面上标记
- 使用 macOS 顶部菜单栏控制
- 在画笔、直线、箭头、矩形、圆形之间切换
- 使用预设颜色或系统色盘
- 选择线条粗细
- 标记状态下显示小笔光标
- 撤回上一步标记
- 清空所有标记
- 在 macOS 顶部菜单栏显示光标曲线图标
- 使用自定义 macOS App 图标

## 运行

```bash
swift run ScreenMarker
```

退出方式：

- 按 `Esc` 暂停标记
- 按 `Cmd + Q`
- 点击顶部菜单栏里的 `退出边记`

## 使用方式

打开 App 后默认不会直接开始画线。需要先点击顶部菜单栏里的光标曲线图标，选择 `画笔`、`直线`、`箭头`、`矩形` 或 `圆形`，然后才会进入标记状态。

当前安全版交互架构：

- 不使用低层鼠标事件钩子，避免系统级卡死风险
- 打开 App 后，透明覆盖层默认鼠标穿透，不影响桌面操作
- 选择工具后，覆盖层接管鼠标用于绘制
- 不再使用浮动工具条，避免工具条和覆盖层抢鼠标事件
- 覆盖层不覆盖 macOS 顶部菜单栏，因此菜单栏控制始终可点击
- 如果需要恢复普通桌面操作，可以点击菜单里的 `暂停标记`，或按 `Esc`

快捷键：

- `1` 画笔
- `2` 直线
- `3` 箭头
- `4` 矩形
- `5` 圆形
- `[` 变细
- `]` 变粗
- `Cmd + Z` 撤回
- `Cmd + K` 清空
- `Esc` 暂停标记
- 标记状态下点击鼠标右键清空

当前安全版优先保证不会拖垮系统。连续标记和阻止 Finder 选择框的高级方案需要单独重做，不再放在当前稳定版里。

## 测试

```bash

```

该脚本会验证：

- 逻辑自检通过
- App 可以启动
- App 进程存在
- App 可以正常停止

## 产品方向

同类 macOS 工具通常包含：

- 屏幕绘制和形状工具
- 光标高亮
- 聚光灯 / 缩放
- 自动擦除标记
- 白板模式
- 带标记截图导出
- 快捷键

首个里程碑保持原生和简单。后续可以继续加入光标高亮、截图导出、全局快捷键、自动淡出和白板模式。
